# Satiscraftory (NeoForge)

Minecraft `1.21.1` NeoForge mod project (Java `21`) with **Create** as a dependency.

## Requirements

- JDK `21`

## Dev

- Build: `gradlew.bat build`
- Run client (dev env): `gradlew.bat runClient`

Runtime files are written to `runs/client/` (logs: `runs/client/logs/latest.log`).
